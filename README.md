# Atividade de IA: Random Forest com Dados de Aeroportos

Atividade da disciplina de Inteligência Artificial da **PUC-SP** (Ciência da Computação). O trabalho aplica **Análise Exploratória de Dados (EDA)** e o algoritmo **Random Forest** a um conjunto de dados de aeroportos.

## Conteúdo do repositório

| Arquivo | Descrição |
|---|---|
| `IA_ML_EDA_RandomForest_Airports.ipynb` | Notebook com a análise exploratória, o treinamento e a avaliação do modelo |
| `Atividade_IA_RF.pdf` | Enunciado / relatório da atividade |
| `README.md` | Este arquivo |

## Objetivo

<!-- Ajuste conforme o enunciado -->
Explorar o dataset de aeroportos, preparar os dados e treinar um classificador/regressor **Random Forest**, avaliando seu desempenho com métricas adequadas ao problema.

## Metodologia

1. **Análise exploratória (EDA):** estrutura dos dados, valores ausentes, distribuições e correlações.
2. **Pré-processamento:** limpeza, tratamento de variáveis categóricas e separação entre treino e teste.
3. **Modelagem:** treinamento do Random Forest com `scikit-learn`.
4. **Avaliação:** métricas de desempenho e importância das variáveis.

## Como executar

### Pré-requisitos

- Python 3.9+
- Jupyter Notebook, JupyterLab ou Google Colab

### Instalação

```bash
git clone https://github.com/LBCapella/Atividade_IA_RF_PUC_SP.git
cd Atividade_IA_RF_PUC_SP
pip install pandas numpy matplotlib seaborn scikit-learn jupyter
```

### Execução

```bash
jupyter notebook IA_ML_EDA_RandomForest_Airports.ipynb
```

Ou abra o notebook diretamente no [Google Colab](https://colab.research.google.com/github/LBCapella/Atividade_IA_RF_PUC_SP/blob/main/IA_ML_EDA_RandomForest_Airports.ipynb).
